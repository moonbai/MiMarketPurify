Privacy Policy

Last updated: 2026-10-04

Mi Market Purify does not collect, store, or transmit any user data.

1. Module Overview

Mi Market Purify (hereinafter referred to as "the Module") is an open-source module built on the LSPosed framework. It performs UI cleanup and feature enhancement exclusively for the Xiaomi App Store (com.xiaomi.market). The Module runs inside the App Store process and has no independent background service.

2. Data Collection

The Module does not collect any user data. Specifically:

  • It does not collect device identifiers (IMEI, Android ID, MAC address, etc.)
  • It does not collect user behavior data (browsing history, search history, download history, etc.)
  • It does not collect the installed-app list
  • It does not collect location information
  • It does not collect any personal information

3. Network Access

The Module declares the INTERNET permission, but only for the following single scenario:

  • When the user actively clicks the "Check for Updates" button, a request is sent to the GitHub Releases API to check for a new version

This request:

  • Is initiated only when triggered by the user; there is no automatic network activity
  • Carries no user device information or personal data
  • Does not report data to any third-party server
  • Does not record or cache network request results for analysis

4. Configuration Storage

The Module uses the LSPosed framework's Remote Preferences to store the user's feature toggle settings. This data:

  • Is stored only on the local device
  • Is synchronized only between the Module App and the App Store process
  • Is not uploaded to any server
  • Is automatically cleared after the Module is uninstalled

5. Third-Party Services

The Module does not integrate any third-party analytics SDK, advertising SDK, or tracking service. The only external service it depends on is GitHub (used solely for checking updates), and it is triggered by the user.

6. Open Source and Transparency

The Module is fully open source (GPL-3.0 license), and all code can be reviewed in the GitHub repository. Any user or security researcher may verify whether the Module's behavior is consistent with this privacy policy.

7. Permission Description

  • INTERNET: only for user-triggered update checks
  • REQUEST_INSTALL_PACKAGES: only for downloading and installing a new APK version after an update check

8. Children's Privacy

The Module is not intended for children under 13 and does not knowingly collect children's personal information.

9. Changes to This Privacy Policy

If this privacy policy changes, it will be updated in the README of the GitHub repository and noted in the changelog on the Module's "About" page. Users are advised to check periodically.
