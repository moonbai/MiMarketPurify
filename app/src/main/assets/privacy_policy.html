隐私政策

最后更新：2026-10-04

Mi Market Purify 不收集、不存储、不上报任何用户数据。

1. 模块概述

Mi Market Purify（以下简称"本模块"）是一个基于 LSPosed 框架的开源模块，仅对小米应用商店（com.xiaomi.market）进行界面净化与功能增强。本模块运行在应用商店进程内，不具有独立后台服务。

2. 数据收集

本模块不收集任何用户数据。具体包括：

  • 不收集设备标识符（IMEI、Android ID、MAC 地址等）
  • 不收集用户行为数据（浏览记录、搜索记录、下载记录等）
  • 不收集应用安装列表
  • 不收集位置信息
  • 不收集任何个人信息

3. 网络访问

本模块声明了 INTERNET 权限，但仅用于以下唯一场景：

  • 用户主动点击"检查更新"按钮时，向 GitHub Releases 接口发起请求以检查新版本

此请求：

  • 仅在用户主动触发时发起，不存在任何自动联网行为
  • 不携带任何用户设备信息或个人数据
  • 不向任何第三方服务器上报数据
  • 不记录或缓存网络请求结果用于分析

4. 配置存储

本模块使用 LSPosed 框架的远程偏好（Remote Preferences）存储用户的功能开关设置。这些数据：

  • 仅存储在本地设备上
  • 仅在模块 App 和应用商店进程之间同步
  • 不会上传到任何服务器
  • 卸载模块后数据自动清除

5. 第三方服务

本模块不集成任何第三方分析 SDK、广告 SDK 或追踪服务。唯一依赖的外部服务是 GitHub（仅用于检查更新），由用户主动触发。

6. 开源与透明

本模块完全开源（GPL-3.0 许可），所有代码可在 GitHub 仓库中审查。任何用户或安全研究者均可验证本模块的行为是否与本隐私政策一致。

7. 权限说明

  • INTERNET：仅用于用户主动触发的检查更新
  • REQUEST_INSTALL_PACKAGES：仅用于检查更新后下载并安装新版本 APK

8. 儿童隐私

本模块不面向 13 岁以下儿童，不会有意收集儿童的个人信息。

9. 隐私政策变更

如本隐私政策发生变更，将在 GitHub 仓库的 README 中更新，并在模块"关于"页面的更新日志中说明。建议用户定期查看。
