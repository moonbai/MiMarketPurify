# Mi Market Purify

> 小米应用商店净化与增强 LSPosed 模块，基于 `callng/NewFuckMarketAds` 使用 AI 辅助重构与扩展。

- **许可**：GPL-3.0
- **作用目标**：小米应用商店（`com.xiaomi.market`），仅在应用商店进程内生效
- **联网行为**：模块自身无后台联网、无上报。唯一的联网点是「关于页 → 检查更新」主动发起的 GitHub Releases 请求（主动点击发起请求，无任何上报行为）

---

## 功能一览

### 广告净化
- 开屏广告
- 前台切换时的广告 / 推荐弹窗
- 首页信息流广告（视频 / 应用推荐、热词栏）
- 搜索建议 / 搜索页 / 搜索结果推荐
- 应用升级页与下载页推荐
- 应用详情页广告、评论区与推荐位、拼装推荐、底部多按钮推广栏、浏览器下载弹窗内的广告列表
- 榜单界面广告 / 推广卡片
- 首页顶栏云控推广位（「看剧」「短剧」等，含换马甲的新增云控位）
- 首页搜索框左侧的云控活动入口
- 「领水果」福利活动入口
- 底部标签页的数字角标与「新」字红点

### 界面精简
- 应用安全检测视图
- 「我的」页：应用推荐与推广、应用管理官方入口、清理与卸载、个人信息区（头像/昵称/消息/收藏）、升级卡片果园背景
- 详情页「精选」
- 底栏自定义：勾选要保留的底部标签，其余隐藏
- 升级记录页推荐（`升级记录` 底部的精选推荐 / 热门下载 / 大家还安装了）
- 搜索页「也在看」（`搜索 xxx 的人也在看`）
- 首页 / 榜单等页面顶部的云控推广子标签
- 更新界面「全部升级」按钮与自动升级开关
- 商店弹出的「升级提醒」对话框（可单独开关）

### 功能增强
- **悬浮底栏**：把贴边的原生底栏换成 Compose 自绘的悬浮圆角胶囊，页面内容延伸到底栏之下
  - 图标拷贝商店自带 Drawable，点击转发给原生 TabView，**导航与埋点语义完全不变**
  - 可选 iOS 风格液态选中高亮（跟随移动的拉伸胶囊 + 落点过冲 + 图标弹性缩放）、3D 液态效果
  - 可选显示标签文字
  - 可自定义：底栏背景色、选中背景色、文字/图标高亮色、圆角大小、距底部高度
- **强制启用下载超级岛**（无视服务端灰度，可单独开关）
- **细节修正**：显示非正版 APP、被隐藏的更新等处理
- **移花接木**：在原生底栏注入一枚「更新」入口并直达更新页（独立于悬浮底栏，关闭悬浮后该入口仍保留）；待更新数量显示在「更新」标签上

### 稳定性（保护性安全网，不受单个开关控制，仅由总开关门控）
- 拦截商店连续崩溃后删除自身的自毁机制
- 打破回滚死锁、重置崩溃计数器
- 配置备份与回滚后自动恢复
- 所有 hook 点均带 try-catch，单点失败不影响其余功能

## 界面与交互

模块自身的主页、二级设置页、关于页，以及注入到应用商店的**悬浮底栏**，均基于 **Compose + MiuiX**（`top.yukonga.miuix.kmp`）实现，视觉对齐 HyperOS / MiuiX 设计规范：

- **主题**：统一使用 `MiuixTheme`，明暗随系统切换（`darkColorScheme()` / `lightColorScheme()`），配色取自 `MiuixTheme.colorScheme`，与原生商店毛玻璃一致；
- **分组卡片**：同一分组的控件放进一整块圆角容器，**组内不画分隔线**，只用留白分行；
- **整行可点**：点标题或空白处即可翻转开关 / 进入子页，触摸目标不小于 48dp；
- **状态表达**：模块是否可用由顶部状态卡说明（激活绿 / 未激活橙），不靠调暗控件；总开关关闭时功能行整行转灰且不可点；
- **入口摘要是求值函数**：主页与各二级页入口行右侧的「已开启 N 个 / 已隐藏 N 个 / 筛选已关闭」等文案，从二级页返回主屏时**自动重算**（订阅 `refreshSignal`，`onResume` 触发刷新）；
- 适配 edge-to-edge，系统栏 insets 分别回填到固定顶栏顶部与内容区底部；主页 / 关于页在滚动内容里为悬浮底栏预留高度，避免底部出现空白栏、末项被遮挡。

> 关于页顶部应用卡片可点击跳转源码仓库；关于页底部提供「检查更新」。

### 检查更新（关于页）
- 点击「检查更新」于子线程请求 GitHub Releases，结果回主线程以 **MiuiX 风格弹窗**（Material3 `AlertDialog` 套 `MiuixTheme`）呈现；
- 发现新版本：展示版本号、大小、更新说明，「下载并安装」走应用内下载，「去发布页」兜底打开 Release 页；
- 下载过程弹 **MiuiX 进度弹窗**：已知总长时显示环形 + 线性进度条与百分比，服务器未回 `Content-Length` 时退化为 indeterminate（「正在获取下载信息…」），完成后经 FileProvider 自动调起系统安装；
- 已是最新 / 请求失败时以 Toast 轻提示。

## 安装与激活

1. 设备已安装 **LSPosed（或兼容 libxposed 的框架）** 且已获取 root；
2. 安装本模块 APK，在框架的**模块列表**中勾选启用本模块；
3. 在模块**作用域**里勾选「应用商店」（`com.xiaomi.market`）；
4. **重启应用商店**（建议顺手重启一次系统界面以确保注入生效）。

主页状态卡会显示「已激活」及当前框架；若显示「模块未激活」，请检查第 2、3 步并重启应用商店。

### 开关何时生效
开关在 hook 每次调用时实时读取远程偏好，支持远程偏好的框架（LSPosed）下一般**无需重启**；个别 ROM 缓存了快照时，重启一次应用商店即可。总开关关闭后所有 hook 直接跳过。

### 隐藏桌面图标
只停用桌面入口的 `activity-alias`（`.LauncherAlias`），`MainActivity` 始终保持启用，因此框架的模块列表仍可打开主页。此前被旧版本锁出的设备，覆盖安装时会自动恢复入口。

## 技术说明

- **Hook 框架**：`libxposed` 101.0.0 + `ezXHelper`
- **UI 技术栈**：模块 App 与悬浮底栏均使用 **Jetpack Compose + MiuiX**（`top.yukonga.miuix.kmp` 0.9.4，含 `miuix-blur-android` 毛玻璃）
  - Compose BOM 统一版本；`material3` 提供 `AlertDialog` / `TextButton` 等基础组件
  - 悬浮胶囊形状依赖 `io.github.kyant0:shapes`（提供 `Capsule`）
- **构建**：AGP 9.x + Kotlin 2.4.20，JDK 21，`compileSdk 37` / `minSdk 33` / `targetSdk 36`
  - 发布构建开启 R8 full mode + `shrinkResources`，并仅保留 `zh-rCN` / `en` 资源以压缩体积
  - 远程偏好经 binder 跨进程获取、配置写入目标 app SP，高频 hook 路径加 500ms TTL 缓存降低开销
- **配置同步**：libxposed 远程偏好，模块侧写入、hook 侧读取，固定 group 为 `settings`；远程偏好不可用时降级读目标 app 的 SP 文件
- **界面元素屏蔽**：不写死「第几层第几个子 View」，改用**资源 id** 与**角标文案**做锚点；`View.onAttachedToWindow` 全量拦截 + 主界面 / 详情页 `onResume` 整树补扫双路径生效
- **多版本兼容**：Hook 逻辑尽量兼容 HyperOS / MIUI 多版本，尽量避免硬编码版本号
